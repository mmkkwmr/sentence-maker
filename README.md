# sentence-makerコマンド

標準入力から読み込んだ3~5個の単語を使って、ランダムに文章を作成します。
文章を考えるきっかけとして利用できます。

## 必要なソフトウェア

Python
 - テスト済みバージョン：3.10〜3.14

## 使い方

標準入力から3~5個の単語を入力して実行します。

入力する単語は、次の順番で指定してください。

1. 動作主
2. 場所
3. 動作
4. 追加する単語（任意）
5. 追加する単語（任意）

## 使用例

### 3語の場合

実行例

```bash
$ echo "魔法使い 古城 探検" | ./sentencemaker
```

出力例

```text
魔法使いは古城で探検をした。
```

### 4語の場合

実行例

```bash
$ echo "探検家 遺跡 調査 古代文字" | ./sentencemaker
```

出力例

```text
探検家は遺跡で調査をしていた。古代文字について考えていた。
```

### 5語の場合

実行例

```bash
$ echo "魔法使い 古城 探検 宝石 地図" | ./sentencemaker
```

出力例

```text
魔法使いは古城で探検をした。宝石と地図を調べていた。
```
## 注意事項

文章のパターンや動作表現はランダムに選ばれるため、入力する単語の組み合わせによっては、不自然な文章が生成される場合があります。

## テスト環境

Ubuntu 24.04 LTS
