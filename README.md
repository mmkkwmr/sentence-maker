# sentence-makerコマンド

標準入力から読み込んだ3~5個の単語を使って、ランダムに文章を作成します。

## 必要なソフトウェア

Python
 - テスト済みバージョン：3.12.3

## 使い方

標準入力から3~5個の単語を入力して実行します。

入力する単語は、次の順番で指定

1. 動作主
2. 場所
3. 動作
4. 目的語（任意）
5. 相手（任意）

##使用例

###3語の場合

実行例
echo "私 洞窟 探検" | ./sentencemaker

出力例
私は洞窟で探検をしました。

###4語の場合

実行例
echo "女の子 公園 散歩 花" | ./sentencemaker

出力例
女の子は公園で散歩をして、花を見つけました。

###5語の場合

実行例
echo "私 森 冒険 宝物 友達" | ./sentencemaker

出力例
私は森で友達と一緒に冒険をして、宝物を見つけました。

##注意事項

文章のパターンや動作表現はランダムに選ばれるため、入力する単語の組み合わせによっては、不自然な文章が生成される場合があります。

## テスト環境
